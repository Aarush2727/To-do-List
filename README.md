# To-Do List

A simple and visually unique To-Do List web application built using HTML, CSS, and Vanilla JavaScript.

The project focuses on combining useful task-management features with a distinctive interface, custom typography, and a design that feels different from typical To-Do List applications.

## Features

- Add new tasks
- Mark tasks as completed or active
- Edit existing tasks
- Delete tasks
- Filter tasks:
  - All
  - Active
  - Completed
- Display the number of remaining tasks
- Clear all completed tasks
- Press `Enter` to quickly add a task
- Tasks are saved using `localStorage`
- Tasks remain available after refreshing the page
- Responsive design for desktop, tablet, and mobile devices
- Empty state when there are no tasks
- Smooth transitions and interactive feedback

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No installation or build process is required.

## How It Works

Tasks are managed using JavaScript and stored in the browser's `localStorage`. This allows tasks to remain saved even after refreshing or reopening the page.

The application provides different filters to easily view all tasks, active tasks, or completed tasks.
